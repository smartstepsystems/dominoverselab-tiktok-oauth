# dominoverselab-tiktok-oauth

Página estática usada como **redirect URI** do fluxo OAuth do **TikTok Login Kit** para o
projeto **dimdim / dominoverselab**. Ela apenas exibe o `code` e o `state` devolvidos pelo TikTok
para você copiar e trocar por um token de acesso no CLI do `publisher`.

- **URL (GitHub Pages):** `https://smartstepsystems.github.io/dominoverselab-tiktok-oauth/`
- **Registrar como Redirect URI** no app do TikTok em *Login Kit → Redirect URI*.

Não contém segredos — é só HTML estático.
